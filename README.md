# Food Recipe App

A responsive web application that allows users to search and explore delicious food recipes using **TheMealDB API**. Built using **HTML, CSS, JavaScript, and Bootstrap**, this app provides an interactive UI with recipe details, ingredients, and cooking instructions.

---

## Features

* Search meals by name
* Display random meals on page load
* View full recipe details
* Dynamic ingredient list generation
* YouTube video link for cooking guide
* Fully responsive design (mobile + desktop)
* Clean UI using Bootstrap

---

## Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (ES6)**
* **Bootstrap 5**

## Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/your-username/food-recipe-app.git
```

2. Navigate to the project folder:

```bash
cd food-recipe-app
```

3. Open `index.html` using Live Server (recommended)

---

## API Used

This project uses the free API:

* https://www.themealdb.com/api.php

Example endpoints:

* Search meals → `/search.php?s=mealName`
* Random meal → `/random.php`

---

## How It Works

* On page load, random meals are fetched and displayed.
* Users can search meals using the search bar.
* Clicking **"View Recipe"** opens a modal with:

  * Ingredients list
  * Cooking instructions
  * YouTube tutorial link
